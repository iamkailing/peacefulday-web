# Peaceful Day — เว็บจอง Ice Bath + Sauna

เว็บนี้ทำแบบเดียวกับเว็บเซียมซี:

- **GitHub Pages** เปิดหน้าเว็บ (ไฟล์ `index.html`, `config.js`, `assets/`)
- **Supabase** (โปรเจกต์ `peacefulday`, องค์กร Peaceful Day) เก็บการจองและเป็นตัวคิดกติกาทั้งหมด ไฟล์ `supabase/schema.sql`

## กติกาที่ระบบบังคับ (อยู่ในฐานข้อมูล ไม่ใช่ในหน้าเว็บ)
- รอบเริ่มทุกชั่วโมง 09:00–18:00 ลูกค้าใช้ได้ 2 ชั่วโมง หยุดวันพฤหัส
- รับต่อรอบ วันธรรมดา 5 คน / เสาร์-อาทิตย์และวันหยุดนักขัตฯ 8 คน
- กันจองเกิน กันจองซ้ำด้วยเบอร์เดียวกันในรอบเดียวกัน ปิดจองออนไลน์ก่อนรอบ 30 นาที
- ลูกค้ายกเลิก/เลื่อนเองได้ก่อนรอบ 24 ชั่วโมง (เลื่อนได้ 1 ครั้ง)
- ตอนนี้ชำระที่ร้าน ทีมงานบันทึกรับเงินตอนเช็คอิน (Stripe ใส่ทีหลังได้)

## แก้ค่าต่าง ๆ
เข้า `#admin` บนเว็บ → ตั้งค่าร้าน (ราคา ความจุ เวลา วันหยุด) · ตารางรอบ (ปิดรอบ ปิดร้าน ตั้งวันหยุดนักขัตฯ) · ทีมงาน (เชิญพนักงาน)

## อัปเดตฐานข้อมูล
เปิด Supabase → SQL Editor → วางทั้งไฟล์ `supabase/schema.sql` → Run (รันซ้ำได้ ไม่ลบข้อมูล)
